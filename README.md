# Teste-post-it

Aplicação web simples de bloco de notas em formato de post-it. O layout usa fundo preto e post-its com cores sólidas, permitindo criar, visualizar e excluir notas de forma rápida.

## Como usar
1. Abra o arquivo `index.html` em um navegador moderno.
2. Escolha a cor do post-it, preencha título e conteúdo (o conteúdo é obrigatório) e clique em **Fixar post-it**.
3. Remova um post-it clicando no **✕** no canto superior direito.
4. As notas são salvas no navegador (localStorage) e ficam disponíveis ao recarregar a página.

Atalhos: **Ctrl/Cmd + Enter** adiciona uma nota a partir da área de conteúdo.
